상태색 팔레트 단계 신설 — `--color-danger-*` · `--color-success-*` · `--color-warning-*`

정본은 강조색 11단계·회색 9단계를 갖고 있는데 상태색은 0단계였다. 그래서 소비자가 상태색
대비 문제를 만나도 참조할 값이 없어 각자 리터럴을 지어 쓰게 된다. 세 색에 500(현재 base) ·
700(자유 텍스트용) · 800(`-soft` 배경 위 텍스트용) 을 추가한다.

**소비자 영향 없음.** 새 이름이라 참조하는 곳이 없다. 기존 토큰의 값은 하나도 바뀌지 않는다.

값은 실제로 얹히는 표면에 대해 sRGB 대비를 재서 골랐다:

|            | `#fff` | `#fafbfc` | 자기 `-soft` |
| ---------- | ------ | --------- | ------------ |
| `-500`     | 1.66~4.40 | 1.60~4.25 | 2.81~3.43 |
| `-700`     | 5.02~5.71 | 4.84~5.51 | 4.25~4.64 |
| `-800`     | 7.03~7.95 | 6.79~7.68 | 6.20~6.50 |

`-500` 은 현재 값이고 전부 AA 미달이다 — 램프를 고정하려고 적어 둔 것이지 텍스트에 쓰라는
뜻이 아니다. `-700` 은 흰/카드 배경 위 자유 텍스트용, `-800` 은 배경이 이미 색을 띤
`-soft` 위 텍스트용이다.

warning 은 앰버 쪽으로 색상을 옮겼다. **4.5:1 을 넘는 노랑은 없다** — 밝다는 것이 노랑의
정의이기 때문이다. 읽히는 경고색은 색상을 벗어나야 한다.

전체 50–950 램프를 만들지 않았다. 소비자가 있는 단계만 넣는다.
